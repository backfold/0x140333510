# ngm:// 실행 URL 파싱 (사용자 제공, 2026-10-18)

출처: 게임 웹 실행 시 Nexon Game Manager(ngm) 프로토콜 URL 1건.
**토큰·a2sk 값은 개인 인증 정보라 본 문서에서 제외(레드랙트).**

## 구조

```
ngm://launch/<percent-encoded 인자열>
```

디코딩 결과 인자:

| 인자 | 값 | 비고 |
|---|---|---|
| `-mode` | `launch` | 실행 모드 |
| `-game` | `94227` | 게임 ID (SuddenAttack) |
| `-passarg` | `175.207.21.11 12000 1 -1 1326428154` | **접속 서버 IP·포트 + 3개 필드** |
| `-token` | `NP11:nest:1326428154:...` (레드랙트) | 세션 토큰. 내부에 passarg 5번째 필드와 동일한 숫자 포함 |
| `-insign_token` | `{"webtoken":"","gid":""}` | 빈 값 |
| `-a2sk` | `act:1792...` (레드랙트) | 활성화 키 |
| `-position` | `GameWeb\|https://sa.nexon.com/main/index.aspx` | 실행 출처 페이지 |
| `-architectureplatform` | `none` | |
| `-timestamp` | `1792267113102` | 실행 시각(ms) |

## 의미 분석

- **passarg 필드 5개**: `[0]=175.207.21.11` (서버 IP), `[1]=12000` (포트),
  `[2]=1`, `[3]=-1`, `[4]=1326428154`.
- `[4]` 값이 `-token` 내부(`NP11:nest:1326428154:...`)에도 등장 →
  **계정/사용자 식별자로 추정 [추론 — 미검증]**.
- `[2]=1`, `[3]=-1`은 채널/서버 인덱스 또는 플래그로 추정 [추론].
- 서버 175.207.21.11:12000 이 첫 접속(로그인/게이트) 엔드포인트.
  월드/인게임 서버는 이 연결의 응답으로 내려올 가능성 [추론].

## 분석 활용

- 로컬 캡처 프록시(`scripts/py/sa_proxy.py`)의 기본 upstream 으로
  175.207.21.11:12000 지정.
- 클라이언트 리다이렉트: passarg IP 를 127.0.0.1 로 치환해 실행
  (`scripts/py/launch-via-proxy.ps1`).
- ngm 인자가 suddenattack.exe 커맨드라인으로 동일 전달된다는 점은
  아직 실행 검증 전 [추정].

## 개인정보 취급

- 토큰/a2sk/timestamp 조합은 재식별 가능 → 저장소 커밋 금지, 본 파일에는
  미포함. passarg 계정 식별자 추정값(13264*****)도 공개 문서에서 마스킹.
